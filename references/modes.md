# Rewrite Modes

Use these modes independently or combine them into a multi-version output.

## Faithful Translation

Use for "翻译", "中译英", "英译中", "保留原意".

- Preserve structure, claims, paragraph order, and rhetorical emphasis.
- Translate idioms by meaning rather than literal wording.
- Keep technical terms consistent; create a glossary if the article is long.
- Improve fluency only when it does not change meaning.

## Polished Rewrite

Use for "润色", "改写", "表达更顺", "更高级".

- Preserve content and order.
- Replace weak transitions, repetitive openings, awkward phrasing, and unclear logic.
- Keep the author's stance and emotional intensity.
- Avoid making the piece sound generically corporate or overly literary unless requested.

## Deep Rewrite

Use for "洗稿", "深度改写", "降重", "换一种说法".

- Preserve the structure and argument route, but rebuild sentences from paragraph purpose.
- Change paragraph openings, examples' wording, transitions, and rhetorical devices.
- Keep claims and evidence accurate, but avoid distinctive source phrasing.
- Use fresh analogies only when they support the same idea and do not distort facts.
- Prefer the reverse outline method for high-originality output: source text to outline, outline to claim cards, claim cards to new draft.

## Style Imitation

Use for "仿写", "模仿风格", "按这个写法写".

- Extract style features: pacing, sentence length, section rhythm, emotional curve, type of examples, headline style, and closing style.
- Apply the style to the user's target topic or material.
- Do not copy unique phrasing, named anecdotes, or signature metaphors from the source.
- If the user gives no new topic, produce a structurally faithful rewrite instead of pretending there is a separate subject.
- Treat style as parameters, not as reusable sentences: rhythm, density, rhetorical habits, evidence style, opening pattern, and closing pattern.

## Localized Adaptation

Use for "本土化", "适合小红书/公众号/知乎/海外读者", "换成中文语境".

- Preserve argument function while changing cultural references, examples, idioms, and platform rhythm.
- Keep unsupported new claims out of the main draft.
- Make calls to action and tone fit the platform.

## Expansion

Use for "扩写", "更完整", "写长一点".

- Preserve the original structure.
- Add explanation, examples, transitions, and counterpoints only where the source logic invites them.
- Label added material mentally during drafting, then verify it is consistent with the source.

## Compression

Use for "缩写", "精简", "压缩到".

- Preserve section order and main claims.
- Remove repetition, secondary examples, and decorative phrasing before removing logic.
- Keep the conclusion's action or emotional landing.

## Multi-Version Set

When the user asks for multiple drafts, make versions genuinely different:

- Version A: faithful and polished.
- Version B: deeper rewrite with stronger originality.
- Version C: platform-optimized or style-imitation version.
- Version D: concise version, if useful.
- Version E: analytical version with clearer hierarchy, if useful.
- Version F: story-driven version with stronger narrative pull, if useful.

Each version should retain the same macro-structure unless the user requests variation.

Assign a clear strategy to every version before drafting. Avoid producing several drafts that only differ by synonyms or sentence length.
